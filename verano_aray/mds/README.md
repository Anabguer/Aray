# MDS — Fitxes d'exercicis per àrea

**MDS** = Markdown Sheet: fitxes d'exercicis editables, alineades amb el currículum de **3r de primària** a Catalunya i amb els materials reals d'Aray.

**Regles obligatòries del temari:** veure [`../regles_temari.md`](../regles_temari.md) abans de crear o modificar qualsevol fitxa.

**Banc d'exercicis (variety + tracking):** veure [`../banc_exercicis/README.md`](../banc_exercicis/README.md)

## Format d'una fitxa MDS

Cada fitxa té:
1. **Capçalera** (curs, àrea, bloc temàtic)
2. **Text o situació breu** (si cal)
3. **4–8 exercicis tancats** (marcar, completar, relacionar, escriure 1–2 línies)
4. **Espai de resposta** (`___` o línies)
