# Iconos ARAY

Recursos PNG con fondo transparente, 418 × 418 px:

- `matematicas.png`: asignatura Matemáticas.
- `catalan.png`: asignatura Catalán.
- `castellano.png`: asignatura Castellano.
- `ingles.png`: asignatura Inglés.
- `medi.png`: asignatura Medi.
- `tablas.png`: actividad Tablas de multiplicar.
- `misiones.png`: acceso a Misiones.
- `coleccion.png`: acceso a Mi colección.
- `drop_robot.png`: Próximo drop / máquina de recompensa.

`MENSAJE_PARA_CURSOR.md` contiene las instrucciones completas de integración y el rediseño responsive de escritorio.

La lámina original con fondo de recorte se conserva en `source/` solo como referencia. La aplicación debe utilizar los PNG individuales de `icons/`.
