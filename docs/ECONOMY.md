# Economía ARAY (contrato)

- **XP → Nivel**: solo al jugar. Umbral: **500 XP / nivel**.
- **Energía → Robux**: jugar + subir de nivel (+20) + cajas + reclamar logros en Mi colección.
- **Tope diario** energía: 100. **Meta ciclo**: 5000 (~50 días a tope).
- **Monedas de tienda**: eliminadas (no hay shop). Las monedas del ejercicio **Dinero** son euros de gameplay.

Fuente de verdad en código: `src/config/economyContract.ts` + `src/config/rewardMatrix.ts`.
