# Inbox de fichas — Inglés

Aquí van los ejercicios / fichas que se pasan para categorizar **antes** de crear packs jugables en la app.

## Qué meter

- PDF, fotos, capturas o texto de ejercicios de inglés
- Un lote por entrega (carpeta o prefijo de fecha si hace falta)

## Qué no meter

- JSON de packs runtime (van en `feinetas/Ingles/*.json` cuando estén aprobados)
- Bancos viejos (están en `_archivo/`)

## Proceso

1. Dejar el material en esta carpeta (`_inbox/`).
2. Actualizar el borrador de categorías: `feinetas/editorial/INGLES_CATEGORIAS_BORRADOR.md`
3. Cuando el mapa de categorías esté cerrado → JSON + estaciones en el hub

Los PDF ya presentes (`1.pdf`…`8.pdf`, `01.pdf`) se movieron aquí desde la raíz de `Ingles/` como material pendiente de clasificar.
