# Errores reales - H

## Objetivo

Este documento recoge errores ortográficos reales relacionados con la H para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** registros contrastados con fichas/materiales del repositorio (`editorial/README.md`). No se copian ejercicios; se reutilizan vocabulario y reglas de 3.º.

**Cruce:** el trío *hay / ahí / ay* tiene documento propio (`ERRORES_REALES_HAY_AHI_AY.md`). Aquí no se duplica ese banco.
