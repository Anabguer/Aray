# Errores reales - GU / GÜ

## Objetivo

Este documento recoge errores ortográficos reales relacionados con **gue/gui** y **güe/güi** (diéresis) para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** misma que los bancos anteriores — fichas primero; calidad antes que cantidad.

**Propiedad:** un lema = un banco. GJ ya apartó gu/gü de su foco g/j.

| Lema / grupo | Banco |
|--------------|--------|
| juego, coger, lenguaje… (g/j) | `ERRORES_REALES_GJ.md` |
| guitarra, cigüeña, pingüino… | este banco |
| hormiguero (h) | `ERRORES_REALES_H.md` |
