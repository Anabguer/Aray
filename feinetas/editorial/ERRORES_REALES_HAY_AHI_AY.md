# Errores reales - HAY / AHÍ / AY

## Objetivo

Este documento recoge errores ortográficos reales del trío **hay / ahí / ay** para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** misma que H, BV, GJ, RR, LL/Y, C/Z/QU y MP/MB — fichas del repositorio primero; calidad antes que cantidad.

**Propiedad de lemas:** este banco es el **único propietario** de *hay*, *ahí* y *ay* (¡ay!).  
No se duplican en H (haber) ni en otros bancos.

| Lema / grupo | Banco propietario |
|--------------|-------------------|
| haber, ha, he, había… (sin el trío) | `ERRORES_REALES_H.md` |
| hay / ahí / ay | este banco |
| ayer (ll/y) | `ERRORES_REALES_LLY.md` |

**Naturaleza del banco:** no es un léxico amplio. Son **tres homófonos** de uso diario cuya confusión es el error infantil. El temario de 3.º los nombra explícitamente; las fichas aportan usos reales (*hay*, *¡ay!*, *ahí*) aunque el drill de contraste completo sea escaso en extractos.
