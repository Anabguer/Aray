# Errores reales - LL / Y

## Objetivo

Este documento recoge errores ortográficos reales relacionados con **ll** e **y** para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** misma que `ERRORES_REALES_H.md`, `ERRORES_REALES_BV.md`, `ERRORES_REALES_GJ.md` y `ERRORES_REALES_RR.md` — fichas del repositorio primero; no copiar ejercicios; sin conjugaciones de relleno.

**Propiedad de lemas (norma del proyecto):** cada palabra tiene un único banco propietario. No se duplican registros.

| Lema / grupo | Banco propietario |
|--------------|-------------------|
| haber, hacer, echar | `ERRORES_REALES_H.md` |
| hay / ahí / ay | `ERRORES_REALES_HAY_AHI_AY.md` |
| caballo, llave, botella | `ERRORES_REALES_BV.md` |
| también (mb) | `ERRORES_REALES_MPMB.md` |

**Cruces (sin duplicar contenido):**
- **caballo, llave, botella** → BV (aunque lleven ll).
- **llamar, yegua** → fuera (sin respaldo de drill).
- Conjugaciones (distribuyó, influye, oyes…) → fuera; solo lemas / infinitivos.
- Sufijos **-illo / -illa** = ll; contraste **y** en playa, ayer, reyes…
