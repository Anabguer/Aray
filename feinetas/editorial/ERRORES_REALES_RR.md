# Errores reales - R / RR

## Objetivo

Este documento recoge errores ortográficos reales relacionados con **r** y **rr** para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** misma que `ERRORES_REALES_H.md`, `ERRORES_REALES_BV.md` y `ERRORES_REALES_GJ.md` — fichas del repositorio primero; no copiar ejercicios; sin conjugaciones de relleno.

**Propiedad de lemas (norma del proyecto):** cada palabra tiene un único banco propietario. No se duplican registros.

| Lema / grupo | Banco propietario |
|--------------|-------------------|
| haber, hacer, echar | `ERRORES_REALES_H.md` |
| hay / ahí / ay | `ERRORES_REALES_HAY_AHI_AY.md` |
| burro, barro | `ERRORES_REALES_BV.md` |
| proteger | `ERRORES_REALES_GJ.md` |
| guitarra | futuro banco GU/GÜ (no RR) |

**Cruces (sin duplicar contenido):**
- **burro / barro** → BV.
- **proteger** → GJ.
- **guitarra**, **barrera**, **barril**, **torre** → fuera de este banco (sin drill RR o foco ajeno).
- Nombres propios → fuera del Banco Maestro.

**Regla de 3.º (Savia u5):** sonido suave = una r; sonido fuerte = r al inicio, **rr** entre vocales, **r** tras n/l/s.

**Nota editorial:** la “r inicial” no se rellena con distractores tipo *rrojo* (artificiales). El contraste r suave se limita a *oreja* y *parar*.
