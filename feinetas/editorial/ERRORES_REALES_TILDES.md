# Errores reales - TILDES

## Objetivo

Este documento recoge errores ortográficos reales relacionados con la **tilde** (agudas, llanas y esdrújulas) para alumnos de 3.º de Primaria en Cataluña.

Este documento es la fuente oficial para crear posteriormente los bancos JSON.

Nunca debe contener palabras inventadas.

**Metodología:** misma que los bancos anteriores — fichas primero; calidad antes que cantidad; un lema = un propietario.

**Propiedad:** solo palabras cuya **dificultad principal** sea la tilde.  
Si el lema ya pertenece a otro banco (c/z/qu, mb/mp, g/j…), **no** se duplica aquí aunque lleve tilde.

| Lema | Banco propietario (no duplicar) |
|------|----------------------------------|
| lápiz, corazón | `ERRORES_REALES_CZQU.md` |
| también, campeón | `ERRORES_REALES_MPMB.md` |
| ágil | `ERRORES_REALES_GJ.md` |
| ahí | `ERRORES_REALES_HAY_AHI_AY.md` |
